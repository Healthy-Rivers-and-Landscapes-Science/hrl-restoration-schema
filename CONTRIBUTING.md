# Contributing

Schema changes should be made through pull requests.

- Edit the LinkML source file, `schemas/hrl_restoration_project.yaml`, not
  generated files.
- Keep schema changes small and reviewable.
- Update documentation when schema meaning changes.
- Add or update examples when validation behavior changes.
- Treat controlled vocabulary changes as schema changes.
- Do not add validation application code, infrastructure, database migrations,
  API code, or map application code to this repository.
